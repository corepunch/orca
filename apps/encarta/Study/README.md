# The Study

The 3D room planned as Encarta's home screen: a desk with a globe and a lamp,
a window onto the night sky, two pictures and a bookshelf. Preview it with

```sh
build/bin/orca -url=/study apps/encarta
```

Everything in this folder except `Textures/` sources and this file is
generated by [`Tools/build_study.py`](../Tools/build_study.py). The room is
described there as boxes, spheres and upright cylinders; edit `build_scene()`
and run the script again.

```sh
python3 apps/encarta/Tools/build_study.py            # meshes, XML, full lightmap (about 15 minutes)
python3 apps/encarta/Tools/build_study.py --draft    # the same with a quick, noisy lightmap
python3 apps/encarta/Tools/build_study.py --no-bake  # meshes and XML only, keep the lightmap
```

Moving, adding or resizing anything changes the lightmap layout, so follow
`--no-bake` with a bake before committing.

## How it is lit

The scene has no runtime lights. `Baked.xml` multiplies each surface's
texture (UV0) and vertex colour by `Textures/lightmap.png` (UV1). The script
path traces that lightmap: a warm bulb in the desk lamp, cool moonlight
through the window, a soft warm fill from the ceiling, and two bounces of
light between surfaces. One lightmap unit of 1.0 means `LIGHTMAP_RANGE`
(4.0) units of light, stored sRGB-encoded.

| File | Contents |
| --- | --- |
| `Scene.xml` | One `Model3D` per material |
| `Meshes.xml`, `Meshes/*.mesh` | Geometry with position, normal, colour, UV0 and UV1 |
| `Materials/*.xml` | Texture and lightmap for each mesh |
| `Baked.xml` | The texture-times-lightmap shader |
| `Textures/lightmap.png` | The baked light, 1024×1024 |

The Poly Haven files are the 1K diffuse maps. To import them again, download
`<name>_diff_1k.jpg` and Natural Earth's `ne_110m_land.geojson` and
`ne_110m_lakes.geojson` into one folder and pass it as `--textures <folder>`.
The two pictures on the wall reuse `Images/Thumbs/octopus.jpg` and
`heart.jpg`.
