# Book Visual Work

This directory owns the Book project's visual-development references and
production process documentation. These materials belong to the illustrated
Book host, not to the zilscript text-adventure source.

## Guides

Start at [../AGENTS.md](../AGENTS.md) for task routing and ownership. `Work/`
contains the canonical visual guides; root duplicates are now link stubs.

- `LOCATION_BRIEFS.md`: authoritative story sources, physical location mapping
  and a reusable brief for connected sets.

- `ARTSTYLE.md`: canonical Wondertown art direction and illustration prompts.
- `CHARACTER_DESIGN_BIBLE.md`: locked character designs and reproduction rules.
- `PROCESS.md`: illustrated-book interaction and image-production workflow.
- `RENDERING.md`: Scener render commands and validation workflow.
- `SCENE_COMPOSITION.md`: connected geography, staged density, cameras, lighting/shadows, occlusion and UI review.

## References

`references/` contains character model sheets and selected final character
images used to preserve visual identity.

Production page images remain in `../illustrations/`. Runtime scenes, screens,
scripts, styles, and generated camera metadata remain in their existing Book
directories.
