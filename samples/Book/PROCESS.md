# «Три звёздочки для карты»

Небольшое приключение на C. Мышка Мира собирает три звёздочки в одной чердачной
комнате: на полу, на столе и на подоконнике. Разговоров, бросков и таймера нет.
Подробный синопсис, география и постановка кадров находятся в [DESIGN.md](DESIGN.md).

## Запуск

Из этой папки:

```sh
make
./three-stars
```

Игра принимает номера доступных действий. `i` показывает инвентарь, `l`
повторяет описание текущей локации, `q` завершает игру. Ожидаемый маршрут
описан в [WALKTHROUGH.md](WALKTHROUGH.md).

Мир описан статическими массивами в `world.c`: три локации, три предмета и
действия с разрешёнными переходами. `main.c` хранит только текущую локацию и
набор найденных предметов. Каждый кадр имеет ID по схеме
`комната-глагол-объект`; программа строит путь `illustrations/<ID>.jpg` без
таблицы ручных соответствий. В терминале путь напечатан рядом с текстом.

## Блок-аут и кадры

`attic.blks` — единая 3D-сцена Scener с тринадцатью камерами. Предметы и
мебель сохраняют координаты между ракурсами. Папка `illustrations/` содержит
рендеры JPG 1536×1152. Для игровых сцен есть три общих вида, два вида после
подбора предметов, по одному кадру на каждое действие и заключительный кадр.

Рендер из корня `mapview/ui`:

```sh
./build/bin/scener --render /path/to/orca/samples/Book/attic.blks \
  --size 1536x1152 --supersample 2 --format jpg \
  --output-dir /path/to/orca/samples/Book/illustrations
```

Всегда сохраняй эти кадры как JPG. Для новых камер действий используй имена
`комната-глагол-объект`; имя файла должно совпадать с ID камеры. После рендера
осмотри тени и композицию каждого кадра, затем отыграй маршрут из
`WALKTHROUGH.md`.
